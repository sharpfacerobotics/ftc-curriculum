# Unit 13 Comprehensive Coding Challenge

The simulator supplies one empty TeleOp class. Design the supporting classes and the OpMode implementation yourself.

## Your Task

1. Create a reusable parent mechanism class with encapsulated hardware state.
2. Create at least one child subsystem with `extends` and specialized behavior.
3. Use `@Override` for behavior that differs from the parent implementation.
4. Centralize hardware names and calibration values as `static final` constants.
5. Create a Robot class that composes multiple subsystem objects.
6. Give the Robot class one `init(HardwareMap)` entry point.
7. Instantiate the Robot in the OpMode, initialize it in `init()`, and control it from `loop()`.
8. Provide one cleanup path that leaves powered mechanisms safe.

The OpMode should read like coordination code. Hardware details belong inside the subsystem classes.
