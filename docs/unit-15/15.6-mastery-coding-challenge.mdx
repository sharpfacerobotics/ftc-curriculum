# Unit 15 Comprehensive Coding Challenge

The editor provides the FTC SDK imports, autonomous registration, and an empty `LinearOpMode` class. Import the five reusable files from your Unit 13 project, then write the autonomous coordinator. Passing every requirement demonstrates full mastery of Unit 15 and completes the software track.

## Your Task

1. Map Limelight 3A as `"limelight"`, select its pipeline, and start it.
2. Create a Pedro Pathing `Follower` and establish a starting `Pose`.
3. Build a `PathChain` that uses both a `BezierLine` and a `BezierCurve`.
4. Create a named `enum` state machine for path and mechanism phases.
5. Call `follower.update()` on every active loop before state logic.
6. Validate each `LLResult` before using it, then fuse a valid global pose back into the Follower.
7. Create and initialize one `RobotHardware` object. Call `robot.update()` every cycle and coordinate `robot.lift` and `robot.intake` with a `getRuntime()` deadline instead of `sleep()`.
8. Keep raw intake and lift hardware access inside their subsystem files.
9. Report path, state, and vision status, then call `robot.stopAll()` and stop the Limelight during cleanup.

No state may block the loop. Vision loss and a busy follower must both be handled as expected operating conditions.
