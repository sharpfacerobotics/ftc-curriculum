# Unit 10 Comprehensive Coding Challenge

The editor provides the FTC SDK imports, autonomous registration, and an empty `LinearOpMode` class, like Android Studio would. Write the full encoder-based move yourself. Passing every requirement demonstrates full mastery of Unit 10, so experienced students can take this challenge first and continue directly to Unit 11.

## Your Task

1. Declare shared constants for ticks per revolution and wheel diameter or circumference.
2. Convert a requested travel distance into encoder ticks.
3. Map the drive motors and reset their encoders.
4. Assign target positions and select `RUN_TO_POSITION`.
5. Apply power only after the targets and run mode are configured.
6. Continue while the OpMode is active and the motors are busy.
7. Report current positions and target error through telemetry.
8. Stop both motors and restore `RUN_USING_ENCODER` when the move ends.

Make the conversion readable enough that a teammate can change wheel size without rewriting the routine.
