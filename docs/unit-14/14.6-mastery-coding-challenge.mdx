# Unit 14 Comprehensive Coding Challenge

The editor provides the FTC SDK imports, autonomous registration, and an empty `LinearOpMode` class, like Android Studio would. Build the complete vision program yourself. Passing every requirement demonstrates full mastery of Unit 14, so experienced students can take this challenge first and continue directly to Unit 15.

## Your Task

1. Map the configured webcam and build an `AprilTagProcessor`.
2. Build a `VisionPortal` with the camera and processor.
3. Iterate safely over current `AprilTagDetection` objects.
4. Read tag ID and `ftcPose` data for navigation telemetry.
5. Define multiple OpenCV `Rect` regions for left, center, and right analysis.
6. Classify a stable three-zone autonomous selection before Start.
7. Report the selected zone and useful detection data through telemetry.
8. Close the `VisionPortal` when camera work is complete.

Treat missing detections as a normal state. Your program must not assume a tag is always visible.
