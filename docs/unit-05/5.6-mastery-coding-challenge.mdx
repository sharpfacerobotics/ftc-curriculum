# Unit 5 Comprehensive Coding Challenge

The editor provides the FTC SDK imports, TeleOp registration, and an empty OpMode class, like Android Studio would. Write the complete decision system yourself. Passing every requirement demonstrates full mastery of Unit 5, so experienced students can take this challenge first and continue directly to Unit 6.

## Your Task

Program a red-alliance sample sorter. Use these Robot Controller configuration names:

- Intake motor: `"intake"`
- Color sensor: `"intake_color"`
- Distance sensor: `"intake_distance"`

Read distance in centimeters and read both color channels once per loop. Then apply this decision order:

1. If the sample is closer than 10 cm and `red > blue`, set intake power to `0.8` and report `COLLECT RED`.
2. Otherwise, if the sample is closer than 10 cm and `blue > red`, set intake power to `-0.5` and report `EJECT BLUE`.
3. Otherwise, set intake power to `0.0` and report `STOP`. This branch covers color ties and samples that are 10 cm away or farther.

Use one `if` / `else if` / `else` chain. Report distance, red, blue, and the selected state through telemetry.

Use the Red, Blue, and No sample controls above the robot view to test every branch after you run your code.
