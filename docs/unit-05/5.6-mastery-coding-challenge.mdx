# Unit 5 Comprehensive Coding Challenge

The editor provides the FTC SDK imports, TeleOp registration, and an empty OpMode class, like Android Studio would. Write the complete decision system yourself. Passing every requirement demonstrates full mastery of Unit 5, so experienced students can take this challenge first and continue directly to Unit 6.

## Your Task

Create a sensor-aware intake controller:

1. Map an intake motor, a color sensor, and a distance sensor.
2. Read the sensors once per loop and store their values clearly.
3. Use an `if` / `else if` / `else` chain so only one power command wins each cycle.
4. Use comparison operators to establish safe sensor thresholds.
5. Use both `&&` and `||` where combined conditions are appropriate.
6. Allow deliberate driver input to run or reverse the intake when it is safe.
7. Include an explicit `setPower(0)` fallback and report the selected state through telemetry.

Your result should fail safely when no branch authorizes movement.
