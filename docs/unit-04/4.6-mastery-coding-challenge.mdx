# Unit 4 Comprehensive Coding Challenge

Start from the empty class shell in the simulator and build the driver controls without fill-in-the-blank scaffolding.

## Your Task

Create a two-motor arcade-drive TeleOp that includes every input technique from this unit:

1. Map left and right drive motors during `init()`.
2. Read forward and turning joystick axes and apply a deadzone to both.
3. Write and call a method that applies a signed sensitivity curve.
4. Use a trigger as an analog speed limit.
5. Use a button to select between precision and full-speed behavior.
6. Mix forward and turn values into left and right power, then clip or normalize the results.
7. Command both motors and publish the final powers to telemetry.

The controls should remain predictable when several inputs are active at once.
