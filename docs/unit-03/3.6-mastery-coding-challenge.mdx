# Unit 3 Comprehensive Coding Challenge

The starter contains only imports, `@TeleOp`, and an empty class. You must decide which fields, lifecycle methods, and statements belong inside it.

## Your Task

Build a motor-control TeleOp that demonstrates every variable type from this unit:

1. Store the motor's configuration name in a `String` and use that variable in `hardwareMap.get()`.
2. Use a `double` as a driver-power scale.
3. Use a `boolean` to track whether precision mode is enabled.
4. Use an `int` to count completed driver actions.
5. Calculate final motor power from gamepad input and the current mode.
6. Report all important values through telemetry so another programmer can debug the state.

Choose clear names and keep each value as a single source of truth.
