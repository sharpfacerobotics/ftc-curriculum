# Unit 2 Comprehensive Coding Challenge

The editor provides the FTC SDK imports, registration annotation, and an empty OpMode class, like Android Studio would. Write the complete implementation inside that class. Passing every requirement demonstrates full mastery of Unit 2, so experienced students can take this challenge first and continue directly to Unit 3.

## Your Task

Build a competition TeleOp that uses the complete iterative OpMode lifecycle:

1. Use `init()` for one-time setup and an initial status message.
2. Use `init_loop()` to repeat a pre-match robot health check.
3. Use `start()` to reset the runtime exactly when Play is pressed.
4. Use `loop()` to read a gamepad value and report live runtime and input telemetry.
5. Use `stop()` to report a clear shutdown state.

Your code must make the purpose of each lifecycle method visible through telemetry. Do not copy a previous lesson's completed class; reconstruct the lifecycle from memory.
