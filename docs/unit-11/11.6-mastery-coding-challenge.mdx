# Unit 11 Comprehensive Coding Challenge

The editor provides the FTC SDK imports, TeleOp registration, and an empty OpMode class, like Android Studio would. Write the complete multi-sensor controller yourself. Passing every requirement demonstrates full mastery of Unit 11, so experienced students can take this challenge first and continue directly to Unit 12.

## Your Task

Program a red-alliance sorter with four safety inputs. Use these Robot Controller configuration names:

- Intake motor: `"intake"`
- Active-low storage switch: `"storage_full"`
- Arm potentiometer: `"arm_pot"`
- Color sensor: `"intake_color"`
- Distance sensor: `"intake_range"`

Configure `storage_full` as a digital input. Its `getState()` value is `false` when storage is full. Scale the potentiometer from 0 to 3.3 V into 0 to 180 degrees with `Range.scale()`.

Read every sensor once per loop. Then apply these rules:

1. Set intake power to `0.8` only when storage is not full, the arm angle is from 20 through 160 degrees, the sample is closer than 10 cm, and `red > blue`.
2. Otherwise, set intake power to `-0.5` when the same storage, angle, and distance checks pass and `blue > red`.
3. Otherwise, set intake power to `0.0`.

Report storage state, arm voltage or angle, distance in centimeters, red, blue, and the selected sorter state.

Use the sample and safety controls above the robot view to test red collection, blue ejection, no sample, and a blocked mechanism.
