# Python Learning Resources

Python is optional. It can give you more practice typing variables, conditions, loops, and functions before Java. These services are separate from Telemark, so their accounts and progress do not sync here.

## Code Club Python

**Best fit for:** learners who want free projects with clear steps.

Code Club provides free project paths from the Raspberry Pi Foundation. Its Introduction to Python path uses variables, functions, and loops to build visual and interactive projects. The browser editor requires no local setup.

[Open Code Club Python](https://codeclub.org/en/learn-to-code)

## Codecademy

**Best fit for:** learners who like short interactive exercises and do not mind an account.

Codecademy has free Python material in its catalog. Its full Learn Python 3 course currently requires a paid plan, so check the price label before starting a course.

[Browse Codecademy Python](https://www.codecademy.com/catalog/language/python)

[Read Codecademy's plan and pricing explanation](https://help.codecademy.com/hc/en-us/articles/360022052834-Price-of-Codecademy)

## CodeChef

**Best fit for:** learners who want many small input-and-output problems.

CodeChef's beginner Python course teaches syntax and provides a large problem set. Some topics are free and some require CodeChef Pro. Its style focuses more on solving exact problems than building visual projects.

[Open CodeChef Python](https://www.codechef.com/learn/course/python)

[Read the CodeChef access FAQ](https://www.codechef.com/faq)

## Python.org

**Best fit for:** learners who want official references and a wider list of tutorials.

Python.org maintains a beginner page and a list for people who have not programmed before. It is more reference-like than the guided courses above.

[Open Python for Beginners](https://www.python.org/about/gettingstarted/)
